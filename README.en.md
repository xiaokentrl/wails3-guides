**English** · [中文](./README.md)

## Usage Rules

1. **Copy the whole directory**: a new project takes the entire `guides/` directory; the 《title》 references between guides travel with it and never break.
2. **The master outline is the entry point**: answer the "core questions" and record the "acceptance evidence" stage by stage; wherever an item says "→ see the topic guide", the topic guide governs.
3. **Topic guides are the deep water**: the master outline only lists gating questions; each topic's full checklists, root-cause tables and acceptance matrices live in the topic guide.
4. **Cross-project assets follow the same rules**: the component library (`ui/`) and the Go shared library (`lib-go/`) accumulate during projects per the Component Library and Shared Functions guides — copy-migration and backflow discipline identical to this library.
5. **Release notes**: changes to this library are recorded bilingually in [RELEASES.md](./RELEASES.md) (Added / Fixed / Updated / Other).

## Conventions for Adding New Topic Guides

- Filename = topic name, placed in `专题/<theme>/`: existing themes take new guides directly; a new theme opens a new directory. Framework-specific deep pitfalls go into the topic guide; universal principles go into the master outline.
- Structure follows one of two skeletons: **discipline master** (what this guide is → the 10–12 questions AI must answer first → core disciplines → root-cause table → test matrix → AI constraint template → five-stage positioning) or **implementation companion** (positioning & hard goals → core design → acceptance checklist → AI constraint template → five-stage positioning); the latter must declare its master guide.
- When adding a guide, update the catalog above; when removing items or changing semantics, check the 《title》 references in other guides.
- Project-specific war stories (which project hit which pitfall) never enter the guides — guides stay generic; lessons go into each project's own docs.
- This README is bilingual: `README.md` (Chinese) and `README.en.md` (English) mirror each other — update both when adding, removing, or changing guides.
