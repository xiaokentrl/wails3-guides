## 四、项目期验证清单（接手即做）

以下「待验证」项需要真实 Wails3 环境逐项核销：

1. **三引擎一致性**：WebView2 / WebKitGTK / Chromium 逐组件冒烟（Pointer Capture、aspect-ratio、CSS 支持基线）
2. **真实 IME**：TextInput / EditableText / PinInput / Mentions / AutoComplete 组合态行为
3. **系统能力接线**：NotificationRouter 桥接注入、Terminal 接 pty、FileDialog 接真实 FS 桥接
4. **网络与离线**：OfflineIndicator 的 WebView online/offline 事件可靠性、RichText 导出接 DOMPurify 消毒
5. **持久化决策**：Whiteboard persistenceKey、Splitter 百分比落定、DatePicker 规范值
6. **权限投影**：PermissionGate 权限键与领域层对齐
7. **深树/大数据**：Cascader 搜索（万级叶）、VirtualizedTree（万级）、Table 虚拟滚动实压
8. **agent 驱动验证**：`WAILS_MCP=1` 启动应用（内嵌 MCP 服务器）——AI agent 驱动真实运行中的应用（窗口控制/DOM 检查/绑定方法调用）批量核销「待验证」项（→《Wails3框架版本判别与服务纪律方案》）
