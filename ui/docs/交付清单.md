## 六、消费方式

```ts
// 消费方只从桶导入（零运行时依赖纪律；集成件除外——自行安装 peer 库后从 integrations/ 引入）
import { Button, Table, MultiSelect, AppShell, exportCsv } from './ui/index';
// 样式：入口处 import './ui/tokens/tokens.css'（唯一令牌源）
// 主题：ThemeProvider（light/dark/system）
// 冒烟入口：docs/EXAMPLES.tsx 挂到任意路由
```

自查管线：`node ui/scripts/check.mjs`（每次改动后必跑）+ `tsc -p .preview/tsconfig.ui.json` + `npx vitest run`。

测试纪律映射（→《Go测试与文件系统模式方案》单测模式族，双端同构）：表驱动 → `it.each` 用例切片；golden files → 快照测试（变更显式审查，禁 `-u` 一把梭）；`t.Helper()` → 自定义断言包装把失败指回用例行；手写 fake → 轻量 stub 优先于重 mock 框架。
