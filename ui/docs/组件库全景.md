# 前端公共组件库全景（组件分类与选型框架）

> 本文是组件库的分类总图：评估/选型先看通用功能层是否完整，再看专项能力是否匹配业务，最后判断架构交付形态是否符合团队策略。横切与质量、协作三层是全部组件共享的地基。

## 〇、总览

```text
前端公共组件库
├── 一、通用功能层（基础 / 布局 / 导航 / 录入 / 展示 / 反馈 / 浮层）
├── 二、弹框家族（打断度分级 27 型 + 8 项横切机制 + 决策树）
├── 三、专项能力层（图表 / 编辑器家族 / 网格进阶 / 日历甘特 / 地图 / 拖拽 / 媒体 / AI / IM / RTC / 文档 / 扫描 / 其他）
├── 四、架构交付层（Headless / 设计系统级 / 三级组件 / 低代码物料 / 跨端多框架 / 工程形态 / 按需交付 / 版本策略 / 工程配套）
├── 五、横切模块层（Tokens 与主题 / i18n / A11y / 安全 / 权限感知 / 埋点 / 性能 / 错误边界 / 手势 / 表单状态 / 动效 / 弹框基础设施）
├── 六、质量保障层（单元 / 交互 / 视觉回归 / A11y / 性能基准 / 类型 / 体积 / 依赖安全 / 专项）
└── 七、协作交付层（文档站 / Starter Kit 与 CLI / 设计协作 / 低代码资产包 / 版本发布与治理 / 贡献流程）
```

## 一、通用功能层

### 1. 基础组件
Button、IconButton、Icon（图标体系：单色线性、可 tint）、Link、Typography（Text / Title / Paragraph）、Divider、Avatar / AvatarGroup、Badge（含点 / 计数变体）、Tag、Kbd（键位标签）、VisuallyHidden（读屏专用隐藏）、TextEllipsis（截断 + 展开）、Highlight（搜索词高亮）、CopyToClipboard、CountUp（数字滚动）、Marker、SafeArea、Portal、AspectRatio

### 2. 布局组件
Grid（栅格）、Flex / Stack / Cluster、Space、Layout / AppShell（侧栏 + 顶栏骨架）、Container（响应式容器）、Divider、Splitter / ResizablePanels（可拖拽分割）、ScrollArea（自绘滚动条——三引擎滚动条差异大，必封装）、Sticky、Collapsible、Masonry（瀑布流）、Center

### 3. 导航组件
Menu / SideMenu、Tabs（含溢出滚动 / 垂直形态）、Breadcrumb、Pagination（含跳页 / 每页条数）、Steps、Dropdown、Anchor、ScrollSpy、BackTop、PageHeader、Toolbar、SegmentedControl、SideNav（树形导航）、FloatingActionButton

### 4. 数据录入 / 表单
Form / FormItem（容器 + 校验时机）、Input、Textarea、InputNumber、PasswordInput（强度计）、PinInput / OTP、SearchInput、AutoComplete / Combobox、Mentions、Select（单 / 多）、TreeSelect、Cascader、DatePicker（单 / Range）、TimePicker（单 / Range）、Checkbox（+ Group）、Radio（+ Group）、Switch、Slider（单 / Range）、Rate、Upload（拖拽 / 分片 / 断点续传 / 目录 / 图片裁剪）、Transfer、TagInput、EditableText（行内编辑）、FormList（动态字段）、SegmentedControl、ToggleGroup、ColorPicker、EmojiPicker、FilePicker

### 5. 数据展示
Table（虚拟滚动 / 可编辑单元格 / 列设置 / 分组 / 汇总行）、List（虚拟列表）、Card、Collapse / Accordion、Descriptions（KV 对）、Timeline、Tree、Progress（bar / ring）、Statistic、Countdown、Carousel、Empty（无数据 / 无权限 / 无网络 / 搜索为空四变体）、Skeleton、QRCode、Watermark、Image（含预览触发）、ImageGroup、Calendar、Heatmap（日历热图）、Gauge、Comment、CodeBlock（高亮 + 复制）、Markdown 渲染、JSONViewer、DiffViewer、StatusDot、FileIcon

### 6. 反馈组件
Alert、Banner、Callout、Message / Toast（+ Provider）、Notification、Modal（AlertDialog / ConfirmDialog / FormDialog）、Drawer、Popconfirm、Spin / Loading、GlobalProgressBar、Result、ErrorBoundary（分级：组件 / 页面 / 应用）、EmptyState 变体、OfflineIndicator、Tour / Onboarding、Skeleton

### 7. 浮层组件
→ 全部归入「二、弹框家族」，不在此重复。

## 二、弹框家族（按打断度分级）

| # | 组件 | 打断度 | 焦点 / 关闭语义 | 用途 |
|---|---|---|---|---|
| 1 | Tooltip | 零 | hover / 焦点显示，不抢焦点 | 悬停提示 |
| 2 | HoverCard | 零 | hover 卡片 | 用户 / 链接预览 |
| 3 | Banner / Callout | 零 | 页内常驻 | 通告、状态 |
| 4 | Toast / Snackbar | 零 | 自动消失，role=status | 操作反馈 |
| 5 | GlobalProgressBar | 零 | 顶部常驻 | 长任务进行中 |
| 6 | OfflineIndicator / StatusPill | 零 | 常驻 | 离线 / 降级 |
| 7 | Popover | 轻 | 点击弹出、light dismiss | 临时内容 |
| 8 | DropdownMenu / ContextMenu | 轻 | 菜单语义、方向键 | 动作菜单 |
| 9 | 各类 Picker 面板（Select / Combobox / DatePicker / ColorPicker / EmojiPicker） | 轻 | 受控浮层 | 选择 |
| 10 | Popconfirm | 中 | 就地确认 | 二次确认 |
| 11 | CommandPalette（⌘K） | 中 | 快开快关 | 命令入口 |
| 12 | NotificationDrawer | 中 | 抽屉 | 消息中心 |
| 13 | ActionSheet / BottomSheet | 中 | 移动形态 | 移动菜单 |
| 14 | Tour / CoachMark | 中 | 序列可跳过 | 引导 |
| 15 | 快捷键速查浮层 | 中 | ? 键唤起 | 可发现性 |
| 16 | AlertDialog / ConfirmDialog | 高 | 模态 + 焦点陷阱 | 破坏性确认 |
| 17 | FormDialog | 高 | 模态 + 表单 | 快速编辑 |
| 18 | Drawer / Slideover | 高 | 侧滑 | 详情 / 设置 |
| 19 | Modal | 高 | 模态 | 通用 |
| 20 | FullscreenDialog | 高 | 全屏 | 重内容 |
| 21 | WizardDialog | 高 | 分步可回退 | 向导 |
| 22 | Lightbox / ImageViewer | 高 | 缩放 / 旋转 / 多图 | 媒体预览 |
| 23 | FilePreviewDialog | 高 | 预览 + 下载 | 附件 |
| 24 | ErrorDialog | 高 | 必须有恢复入口 | 终态错误 |
| 25 | PermissionDialog | 高 | 授权引导 + 再引导 | 权限前置 |
| 26 | LoadingOverlay | 高 | 阻断一切，慎用 | 极少场景 |
| 27 | ModelessDialog | 低 | 可多开并行 | 桌面多窗 |

**弹框横切机制（8 项基础设施）**：① z-index 栈管理器（嵌套自动递增）② 焦点返回链（逐层归还）③ Escape 分层语义（只关最上层）④ 滚动锁定引用计数 ⑤ 弹框队列（并发到达排队呈现）⑥ 移动端降级（Modal → Fullscreen / BottomSheet）⑦ 路由集成（弹框即路由状态）⑧ 触发源锚定（定位 / 滚动跟随 / 边界翻转）。

**选型决策树**：能用 Toast 不用 Dialog → 能用 Banner 不用 Modal → 能就地确认（Popconfirm）不弹窗 → 确需模态选最低打断形态。

## 三、专项能力层

> **实装状态（2026-11-06）**：本层前六项已按「集成封装四件套模式」落地首批 6 件——图表（echarts）、地图（leaflet）、代码编辑器（monaco）、终端（xterm）、富文本（tiptap）、白板（tldraw），见 `integrations/`，模式详见各文件头注释；其余条目为选型清单，按同一模式扩展。

- **图表 / 可视化**：✅ 基础图表（echarts 已实装）；关系图、地理可视化、3D、仪表盘组合、拓扑图、大屏（自适应缩放容器）待按需
- **编辑器家族**：✅ 富文本（tiptap 已实装）、代码编辑器（monaco 已实装）、白板（tldraw 已实装）；Markdown、JSON / Diff、邮件编辑器、表单设计器（schema 驱动：Formily / RJSF）、审批流 / 流程设计器（BPM UI）、报表 / 大屏设计器、规则引擎 UI、思维导图待按需
- **表格进阶**：可编辑数据网格（AG Grid）、透视表、在线表格（Univer / Luckysheet）
- **日历与时间**：日程视图（FullCalendar）、甘特图（dhtmlxGantt / frappe-gantt）、资源排期
- **地图 / GIS**：✅ Leaflet 已实装；OpenLayers、Mapbox GL / MapLibre、Cesium、室内图待按需
- **终端**：✅ xterm 已实装（TerminalRef 命令式写屏；Shell 接 pty 属系统能力方案）
- **拖拽 / 排序**：dnd-kit、看板（Kanban board）、跨容器拖放
- **媒体**：视频 / 音频播放器、直播、弹幕、录屏（RecordRTC）、截图（html2canvas）、图片编辑（裁剪 / 标注）、3D / AR（three.js、model-viewer）
- **AI / 对话**：聊天气泡、流式响应、会话列表、Prompt 输入区、AI 生成 UI（v0 型）
- **IM / 客服**：会话列表、消息流、输入区、已读回执、客服工作台
- **RTC / 会议**：声网 / 腾讯云快捷集成 kits
- **文档 / 打印**：PDF 预览（PDF.js）、Office 预览、打印套件（分页控制 / 小票 ESC/POS）、幻灯片（reveal.js）
- **扫描 / 识别**：相机扫码 / 条码、OCR / 证件识别 UI
- **其他**：终端模拟器（xterm.js）、签名板（SignaturePad）、游戏化（排行榜 / 成就徽章）

## 四、架构交付层

- **Headless / 无头**：Headless UI、Radix UI、Ark UI、React Aria、TanStack Table——行为与样式解耦
- **设计系统级**：Carbon、Fluent UI、Polaris、Ant Design——Tokens + 主题 + 规范 + 治理
- **三级组件**：基础 UI（跨项目）→ 通用业务组件（AdvancedTable / SearchForm / OrgSelector）→ 领域组件（行业专用）
- **低代码物料**：组件 → 区块 → 模板三级
- **跨端 / 多框架**：PC Web / H5 / 小程序 / RN / Flutter；React / Vue / Web Components
- **★ 工程形态**：单包 vs Monorepo 分包（pnpm workspace + changesets）
- **★ 按需交付粒度**：Tree-shaking（ESM + sideEffects:false）、子包独立安装、插件化扩展点
- **★ 版本策略**：统一版本 vs 独立版本（changesets 混合治理）；码 / 枚举与 API 冻结纪律；弃用档案 + Codemod 自动迁移
- **★ 工程配套**：文档工作台（Storybook / dumi）、测试与视觉回归（Chromatic / Loki）、Tokens 工具链（Style Dictionary 多端输出）、微前端共享（Module Federation + 版本仲裁）、Web Components 封装、SSR / RSC 兼容（portal 的 hydration）、主题编辑器（运行时换肤）、AI 生成 UI、多版本共存与灰度切换

## 五、横切模块层

- **Design Tokens / 主题包**：语义令牌单源、亮暗高对比三主题、accent 策略、运行时换肤、裸值审计进 CI
- **i18n / locale 子包**：一语言一文件、Intl 封装单点、RTL、键齐性 parity 门
- **A11y**：内建能力（语义 / 焦点 / 键盘全路径 / 第二通道）+ 独立测试工具层（axe、读屏走查）
- **安全**：CSP 兼容、HTML 消毒（DOMPurify）、URL / scheme 消毒、不可信内容 iframe sandbox
- **权限感知**：PermissionGate 组件（隐藏 / 禁用 / 替换三策略）——UI 只是投影
- **埋点与行为分析**：曝光 / 点击上报统一约定
- **性能**：虚拟滚动、懒挂载、代码分割、Web Vitals 预算
- **错误边界**：组件 / 页面 / 应用三级
- **手势与触屏**：长按 / 滑动 / 双指缩放，桌面触屏双模
- **表单状态与校验协议**：react-hook-form 对接、结构化错误 `{field, code, params}`
- **动效偏好**：prefers-reduced-motion 全局归零、View Transitions API（待验证）
- **弹框基础设施**：见「二」的 8 项机制（做成基础设施，不逐弹框重写）

## 六、质量保障层

单元（纯逻辑 / hooks）· 交互（RTL + 键盘全路径）· **视觉回归**（三引擎截图对比——跨引擎一致性靠它）· A11y（axe 自动 + 读屏走查）· 性能基准（NFR 表 / 渲染性能 / size-limit 体积）· 类型（tsc 严格）· 依赖安全（audit / CVE）· 专项（IME 组合态、区域格式、RTL 布局）· 示例可运行验证（文档即测试）

## 七、协作交付层

- **文档站 / Storybook**：可交互 playground，文档即示例
- **Starter Kit / CLI**：新组件脚手架（模板 + 组件卡骨架 + 目录登记）
- **设计协作**：Figma tokens 双向同步、设计走查流程
- **低代码资产包**：组件 → 区块 → 模板的资产化输出
- **版本发布与治理**：双语 Releases（新增 / 修复 / 更新 / 其他）、弃用档案、消费端回流纪律
- **贡献流程**：查重（目录登记表）→ 三次规则 → 入库四件套（组件卡 / 三引擎冒烟 / 交互 + a11y 测试 / 可运行示例）→ 评审登记

## 贯穿全库的铁律（所有层共同遵守）

1. 样式只引用 Design Tokens，禁裸值（审计进 CI）
2. 输入组件遵守 IME 组合态纪律：组合中不改写
3. 权限判定住领域层，UI 只是投影
4. 状态不只靠颜色（第二通道）
5. 平台相关行为先实机验证，未验证标「待验证」
6. 组件改动必须回流上游，禁止 fork 静默修改
